# Roam IoT — Sign in

Responsive login UI from the Roam IoT Figma designs.

## Breakpoints

| Viewport | Width | Layout |
| --- | --- | --- |
| Desktop | ≥ 1200px | Log In – Direction 01 (split brand + form) |
| Tablet | 768px – 1199px | Log In – Tablet (centered card) |
| Mobile | ≤ 767px | Modernized Continuity (stacked form) |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
